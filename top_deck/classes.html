Classes

A character's class defines their primary abilities, combat style, and approach to challenges. Each class has its own page containing its level progression, core features, subclasses, and class-specific feats.

Maximum Level: 5

Characters advance through five levels of class progression. After reaching level 5, characters continue to develop by acquiring Feat Points and purchasing additional abilities.

II

Class Design

Each class follows the same basic progression while maintaining a distinct identity.

  • Level 1: Core class identity and starting proficiencies.
  • Level 2: Gain a subclass feature.
  • Level 3: Gain a major class feature and increase hand size to 3.
  • Level 4: Gain another subclass feature.
  • Level 5: Increase one Core Attribute by +1 and increase hand size to 4.

Subclasses are built from independent features rather than a fixed linear progression. This allows two characters using the same class and subclass to develop differently.

III

Future Classes

New classes can be added to this index without changing the existing class pages. Each new class should receive its own HTML page using the same shared stylesheet, header, and footer.

Potential future classes might include specialized martial, magical, or hybrid archetypes. New classes should introduce a distinct relationship with the card economy rather than simply duplicating an existing class's role.
